# dots

Personal dotfiles for a CachyOS Hyprland workstation.

This repository is a modular configuration system, not a direct mirror of `$HOME`. Each tool lives in its own component, theme values are centralized, and the installer can apply the full desktop or selected pieces.

## Goals

- Configure the full desktop environment and user tools from one repository.
- Keep visual consistency across Hyprland, Kitty, Waybar, Wofi, browser helpers, scripts, and future tools.
- Support both full installation and targeted component installation.
- Keep generated visual files reproducible from theme definitions.
- Leave room for future host-specific differences without overengineering the current VM/workstation setup.
- Use `docs/` as living documentation for architecture, decisions, components, and implementation notes.

## Architecture

The repository should be organized around three main layers:

```text
themes/       Visual source of truth
components/   Tool-specific configuration
packages/     CachyOS/Arch package groups
hosts/        Host profile defaults
bin/          Helper commands
install.sh    Central installer and orchestration entry point
```

The intended structure is documented in detail in [`docs/architecture.md`](docs/architecture.md).

## Operating Model

- Functional configuration lives under `components/<tool>/config/`.
- Theme-dependent files are generated by `bin/dots-theme-apply`.
- Theme definitions live under `themes/<theme-name>/colors.env`.
- `install.sh` supports non-interactive full and component installs.
- `bin/dots` provides basic day-to-day operations.

## Usage

```bash
./install.sh --packages base,desktop,fonts
./install.sh --all
./install.sh --component kitty
./install.sh --component hypr,waybar,wofi
./install.sh --theme current
./install.sh --all --dry-run

dots install all
dots install packages base desktop fonts
dots install kitty waybar
dots theme list
dots theme apply current
dots services enable
dots doctor
```

## Fresh CachyOS VM

For a fresh CachyOS install without a desktop, use this order from a TTY:

```bash
sudo pacman -Syu --needed git
git clone <repo-url> ~/dots
cd ~/dots
./install.sh --all --dry-run
./install.sh --all --yes
./bin/dots services enable
reboot
```

`--all` installs the host package groups from `hosts/current/packages.txt`, links component configs, and applies the current theme. `dots services enable` enables `NetworkManager`, `bluetooth`, and `sddm` when those services exist.

Initial version with imported configs for Hyprland, Waybar, Wofi, Kitty, Mako, and the current theme palette.

The Hyprland configuration intentionally does not include the removed `dwindle:pseudotile` option from Hyprland 0.55.x. The `SUPER+P` pseudotile dispatcher is kept as a keybind.
